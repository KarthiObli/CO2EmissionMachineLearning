CO2 Emission Prediction

A Machine Learning project that predicts vehicle CO2 emissions based on engine specifications and fuel consumption data.

## Project Overview
This project explores the relationship between vehicle characteristics and CO2 emissions using Linear Regression. The workflow includes data preprocessing, exploratory data analysis (EDA), feature engineering, model training, and performance evaluation.

## Dataset Features
- Engine Size (L)
- Cylinders
- Transmission
- Fuel Type
- Fuel Consumption (City, Highway, Combined)
- Vehicle Class
- CO2 Emissions (Target Variable)

## Project Workflow
- Data Cleaning & Preprocessing
- Exploratory Data Analysis (EDA)
- Feature Encoding & Scaling
- Linear Regression Model
- Cross-Validation & Model Evaluation

## Model Performance
- R² Score: **0.989**
- MAE: **2.91**
- RMSE: **6.14**

The model explains approximately **98.9% of the variance** in CO2 emissions, indicating excellent predictive performance.
